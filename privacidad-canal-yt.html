Política de privacidad de canal-yt

Última actualización: 23 de noviembre de 2026

Qué es canal-yt

canal-yt es una herramienta interna de Visual Shift. Con el permiso del propietario de cada canal, sube videos y lee las estadísticas de los canales de YouTube que administra Visual Shift. No es una aplicación pública ni se ofrece a terceros.

Qué datos usa

Solo a través de los Servicios de API de YouTube, y solo del canal que dio el permiso:

  • Datos del canal: nombre, identificador, videos, listas de reproducción, títulos, descripciones y miniaturas.
  • Estadísticas de YouTube Analytics: vistas, tiempo de reproducción, retención, suscriptores, impresiones y, si el canal está monetizado, ingresos estimados.

canal-yt no accede al correo, a los contactos ni a ningún otro servicio de la cuenta de Google.

Para qué los usa

Para subir y editar los videos del canal, cargar la información del canal y armar informes internos sobre su rendimiento. Para nada más.

Dónde se guardan y con quién se comparten

  • El permiso y las estadísticas se guardan en el equipo de trabajo de Visual Shift. No se suben a servidores de terceros.
  • No se venden, no se comparten y no se usan para publicidad.
  • Los informes se comparten solo con el propietario del canal.

Cuánto tiempo se guardan

Mientras el permiso esté vigente. Si el propietario quita el permiso, los datos guardados se borran dentro de los 30 días, o antes si lo pide.

Cómo quitar el permiso

El propietario puede quitar el acceso de canal-yt en cualquier momento desde la configuración de seguridad de su cuenta de Google: security.google.com/settings/security/permissions.

YouTube y Google

  • canal-yt usa los Servicios de API de YouTube. Al autorizarlo, el propietario acepta las Condiciones del Servicio de YouTube.
  • El uso que hace Google de los datos se rige por la Política de Privacidad de Google.
  • El uso que canal-yt hace de la información recibida de las APIs de Google cumple con la Política de Datos del Usuario de los Servicios de las APIs de Google, incluidos los requisitos de Uso Limitado.

canal-yt privacy policy

Last updated: November 23, 2026

canal-yt is an internal Visual Shift tool. With each channel owner's permission, it uploads videos and reads statistics for the YouTube channels Visual Shift manages. It is not a public application.

  • Data used (only through the YouTube API Services, only for the authorizing channel): channel data (name, ID, videos, playlists, titles, descriptions, thumbnails) and YouTube Analytics statistics (views, watch time, retention, subscribers, impressions and, if monetized, estimated revenue). No access to email, contacts or other Google services.
  • Purpose: uploading and editing the channel's videos, setting up the channel's information and preparing internal performance reports. Nothing else.
  • Storage and sharing: the authorization and statistics are stored on Visual Shift's work computer, not on third-party servers. They are not sold, shared or used for advertising. Reports are shared only with the channel owner.
  • Retention: while the authorization is active. If the owner revokes it, stored data is deleted within 30 days, or sooner on request.
  • Revoking access: at any time via the Google security settings page: security.google.com/settings/security/permissions.
  • canal-yt uses the YouTube API Services. By authorizing it, the owner agrees to the YouTube Terms of Service. Google's use of data is governed by the Google Privacy Policy. canal-yt's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Contact: visualshift.site/contacto.html
